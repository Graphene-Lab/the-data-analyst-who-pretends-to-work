# Приложение A — Глоссарий терминов

Определения терминов, используемых в этой книге, простым языком.

**Агент / агентный.** Программное обеспечение, что совершает *действия* к цели, а
не просто отвечает на вопросы. Агент замыкает петлю от намерения к результату.

**AgentBridge.** Локальный ИИ-ассистент на простом языке, что планирует и
действует сквозь инструменты. «Мозг» в этой книге.

**PowerBITool.** Плагин AgentBridge, управляющий Microsoft Power BI Desktop.
«Руки» в этой книге.

**Power BI Desktop.** Инструмент Microsoft для построения моделей данных и
отчётов.

**Модель.** Набор таблиц, столбцов, мер и связей, который Power BI использует,
чтобы отвечать на вопросы.

**Таблица.** Набор строк и столбцов. Базовый контейнер для данных.

**Столбец.** Одно поле в таблице с типом данных (текст, число, дата).

**Мера.** Вычисляемое значение (обычно агрегат вроде суммы или среднего), что
отзывается на фильтры в отчёте.

**Вычисляемый столбец.** Новый столбец, добавленный в таблицу, вычисленный
формулой для каждой строки.

**Вычисляемая таблица.** Новая таблица, созданная из формулы, вычисленная на
лету.

**Связь.** Ссылка между двумя таблицами (например, Sales → Products), чтобы данные
текли между ними.

**Кардинальность.** Природа связи «один-ко-многим» или «многие-к-одному».

**DAX.** Data Analysis Expressions — формульный язык Power BI.

**SQL.** Structured Query Language — стандартный язык запросов к базам данных.

**SUM / AVERAGE / COUNT.** Базовые агрегаты: итог, среднее и количество.

**DISTINCTCOUNT.** Количество уникальных значений.

**CALCULATE.** Функция DAX, меняющая контекст фильтрации меры.

**FILTER.** Функция DAX, оставляющая строки, подходящие под условие.

**RELATED.** Функция DAX, достающая значение из связанной таблицы.

**DIVIDE.** Безопасная функция деления, обрабатывающая деление на ноль.

**ALL.** Функция DAX, снимающая фильтры (часто для «% от общего»).

**RANKX.** Функция DAX, ранжирующая строки по значению.

**TOPN.** Функция DAX, возвращающая верхние N строк.

**Контекст фильтрации.** Набор фильтров, применённых в данный момент, когда мера
вычисляется.

**Контекст строки.** «Текущая строка», когда вычисляемый столбец или итератор
вычисляет.

**Итератор.** Функция DAX (SUMX, AVERAGEX), что вычисляет строку за строкой.

**Словарь данных.** Документация каждой таблицы, столбца и меры в модели.

**Профилирование.** Осмотр различных значений таблицы, пустот, мин/макс и
примеров.

**Линтинг.** Статические проверки, флагующие рискованные паттерны (например, `/`
вместо `DIVIDE`).

**Лучшие практики.** Медосмотр модели против известных хороших паттернов.

**Fail-closed предохранитель.** Правило безопасности, блокирующее всё явно не
разрешённое.

**Качество данных.** Насколько данные чисты, полны и заслуживают доверия.

**Сегментация.** Разделение клиентов или данных на группы для анализа.

**Сезонность.** Регулярные, повторяющиеся паттерны во времени.

**KPI.** Key Performance Indicator — метрика, важная для бизнеса.

**Дашборд.** Вид ключевых KPI, обычно на одном экране.

**Отчёт.** Подробный, интерактивный набор визуалов, построенный на модели.

**Управление данными.** Правила, владение и контроль вокруг актива данных.

**Парадокс Джевонса.** Когда что-то дешевеет, мы используем его больше, а не
меньше.
