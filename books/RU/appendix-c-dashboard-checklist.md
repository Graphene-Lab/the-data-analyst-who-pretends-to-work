# Приложение C — Чек-лист дашборда

Прежде чем выкатить дашборд, пройдите по этому списку.

## Назначение

- [ ] Дашборд отвечает на ясный вопрос (или набор вопросов).
- [ ] Аудитория известна (руководство, операционка, аналитик).
- [ ] Решение, которое он поддерживает, известно.

## Раскладка

- [ ] Важнейшее число — самое крупное и слева сверху.
- [ ] Связанные метрики сидят вместе.
- [ ] Ничто не конкурирует за внимание.
- [ ] Влезает в один экран без прокрутки (для основного вида).

## Метрики

- [ ] Каждая KPI определена и понята.
- [ ] KPI — *правильные*, а не просто лёгкие.
- [ ] Единицы и форматы ясны (€, %, количества).
- [ ] Каждое число можно проследить обратно к модели.

## Визуалы

- [ ] Тип диаграммы подходит данным (столбцы для сравнения, линия для тренда и
  т.д.).
- [ ] Никакой вводящей в заблуждение оси, никакого отобранного вручную окна.
- [ ] Цвета что-то значат (не украшение).
- [ ] Метки читаемы одним взглядом.

## Интерактивность

- [ ] Фильтры работают и осмысленны.
- [ ] Проваливание в деталь идёт туда, где пользователь ждёт.
- [ ] Перекрёстная подсветка ведёт себя корректно.

## Доверие

- [ ] Числа сходятся с источником.
- [ ] Модель прошла проверку лучших практик.
- [ ] Дашборд задокументирован (что значит каждая KPI).
- [ ] Кто-то владеет им и держит свежим.

## Честность

- [ ] История, что рассказывает дашборд, честная.
- [ ] На трудный вопрос о числе можно ответить без смущения.

Хороший дашборд — не самый красивый. Это тот, которому люди доверяют настолько,
чтобы действовать по нему. Стройте сначала для доверия, потом для красоты.
